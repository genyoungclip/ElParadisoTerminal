# Changelog

All notable changes to this project are documented here. Format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] — 2026-08-19
### Added
- First public release.
- VT100/xterm-256color terminal emulator.
- bash, zsh, fish and Microsoft PowerShell 7 shells.
- APT-style package manager backed by `elp.elparadisogonzalo.net`.
- Multi-session UI, extra-keys row, Material 3 theme.
- GitHub Actions workflows: android-release, android-debug, deploy-site,
  bootstrap-build, apt-repo, play-store, fdroid, codeql.
- Fastlane metadata for F-Droid & Google Play.
- Static marketing site + APT repo + bootstrap mirror hosted on
  `elp.elparadisogonzalo.net`.
