# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 1.x     | ✅ |
| < 1.0   | ❌ |

## Reporting a vulnerability

Please email **security@elparadisogonzalo.net** with details.
Do **not** open a public issue. We aim to acknowledge within 48h and ship a fix
within 14 days for high-severity reports.

GPG key: https://elp.elparadisogonzalo.net/security.gpg
