# Contributing

We follow the standard fork-and-PR flow.

1. Fork the repo, create a feature branch: `git checkout -b feat/awesome`.
2. Run `./gradlew ktlintFormat lintDebug testDebugUnitTest` before pushing.
3. Sign your commits (`git commit -s`) — we use DCO.
4. Open a PR against `main`. CI must be green.
5. Squash-merge policy: keep commit history clean.

See `docs/README.md` for the full developer setup.
