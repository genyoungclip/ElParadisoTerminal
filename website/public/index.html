Install in 30 seconds

1

Download the APK for your device architecture.

arm64-v8a armeabi-v7a x86_64 Universal
2

Allow install from unknown sources, then open the file.

3

Launch El Paradiso Terminal. Bootstrap downloads automatically from this domain.

4

Run pkg install <whatever>. Done.
